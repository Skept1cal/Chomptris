# Chomptris

*Chomptris* is a terminal-based, unofficial tetris clone. Unofficial as from what I know this game diverges from how tetris clones generally work,
in terms of mechanics, mainly.

### How to download

You can either compile the game or download executables from the releases.

### Help

All mechanics, controls and things related to how the game works are detailed within the game's help text.
To open it, press CTRL+H after launch.
